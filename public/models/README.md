# Rocket model

The four `rocket_*.glb` pieces in this directory are from Kenney's
[Space Kit 2.0](https://kenney.nl/assets/space-kit) (2020). Kenney released the
pack under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
The rocket is assembled and animated in `src/game/VoyageScene.tsx`; the rest
of the asset pack is not bundled.
